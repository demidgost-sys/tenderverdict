# Devpost draft — required entry point

The canonical English submission draft is
[submission/devpost-draft.md](../submission/devpost-draft.md). It contains the project title,
tagline, problem, product flow, implementation, RevenueCat integration, challenges,
accomplishments, lessons, next steps, judging proof, exact competition source, pushed candidate,
video URL, and video SHA-256.

This compatibility entry point preserves the filename required by the original project brief while
keeping submission wording in one authoritative document.
