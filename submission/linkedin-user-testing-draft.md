The same tender can be worth opening for one supplier profile — and an immediate reject for
another.

That is the problem I turned TenderVerdict into a native macOS app for RevenueCat Shipaton 2026
Next Gen.

TenderVerdict takes one normalized public-tender feed and evaluates it independently for up to five
named supplier profiles. Each notice becomes one of three review states:

- Open documents
- Watch
- Reject

Every result keeps its reasons, missing information, source link, and next human step. There is no
score, ranking, or automatic bid decision.

Since the first developer alpha, I have added:

- a native Profile Builder and guided CSV/JSON import preview;
- a complete free first-profile review with deterministic JSON export;
- Portfolio Workspace comparison and evidence drill-down across up to five profiles;
- the official RevenueCat Apple SDK, Test Store purchase, entitlement refresh, and restore;
- local-first analysis with no tender files uploaded and no telemetry;
- 125 Python tests, 19 Debug plus 19 Release native checks, and green CI.

Shipaton Manager Perttu Lähteenlahti has confirmed that Test Store is enough for the Next Gen
category. This is still an experimental developer build — not a production procurement tool,
legal advice, or an automatic bid decision.
