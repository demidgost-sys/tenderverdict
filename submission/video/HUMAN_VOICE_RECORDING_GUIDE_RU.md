# Запись озвучки своим голосом

Статус: владелец выбрал собственный голос. AI voice, voice cloning, paid trial и сторонняя
генерация для текущего ролика не нужны.

## Что записать

- Восемь отдельных блоков из [`human-voice-cues.tsv`](human-voice-cues.tsv), минимум по два дубля.
- Один непрерывный полный дубль для интонационного референса; монтаж может использовать блоковые
  дубли.
- 10 секунд room tone в той же позиции и с теми же настройками микрофона.
- Произносить только текст из [`HUMAN_VOICE_MARKED_SCRIPT_EN.md`](HUMAN_VOICE_MARKED_SCRIPT_EN.md).
  Режиссёрские пометки и таймкоды не читать.

## Технический формат

- WAV, mono, PCM 24-bit, 48 kHz; не MP3, AAC или voice-message codec.
- Сухая запись без музыки, реверберации, шумоподавления, auto gain, компрессии, EQ и
  voice-enhancement.
- Пики ориентировочно от −12 до −6 dBFS; ни одного клипа до 0 dBFS.
- Микрофон на уровне рта, 15–20 см, слегка в сторону от воздушной струи; одинаковая дистанция во
  всех дублях.
- Оставлять примерно секунду тишины до и после каждого произнесённого блока; raw takes не
  подрезать.

## Перед записью

1. Закрыть окна, отключить уведомления и вентиляторы, которые можно безопасно отключить.
2. Выбрать один микрофон и явно зафиксировать 48 kHz / 24-bit / mono.
3. Записать короткий тест и самостоятельно проверить отсутствие клиппинга, гула, эха и треска.
4. Проговорить сложные названия по pronunciation block в marked script.
5. Открыть [`human-voice-teleprompter.html`](human-voice-teleprompter.html). Он работает локально,
   не использует сеть, микрофон, autoplay или звук.

## Порядок сессии

1. Записать room tone: `TV_VO_roomtone.wav`.
2. Записать один полный проход без остановок, даже если есть мелкая ошибка.
3. Записать блоки `01–08` по два раза: `..._T01.wav`, затем `..._T02.wav`.
4. Для ошибок записывать только pickup целого предложения, не отдельного слова.
5. Заполнить [`HUMAN_VOICE_TAKE_LOG.md`](HUMAN_VOICE_TAKE_LOG.md), не удаляя невыбранные raw takes.

Raw-файлы складывать в игнорируемый каталог `submission/video/human-voice-takes/`. Имена:

```text
TV_VO_roomtone.wav
TV_VO_full_T01.wav
TV_VO_01_problem_T01.wav
TV_VO_01_problem_T02.wav
...
TV_VO_08_boundary_T02.wav
```

## Монтаж выбранных дублей

- Сначала выбрать интонационно естественные takes, затем выровнять их по `in_s` / `out_s` из TSV.
- Не ускорять и не растягивать голос. Если блок длиннее слота, перезаписать его спокойнее и короче
  по паузам.
- Паузы между блоками заполнять room tone, а не цифровой абсолютной тишиной.
- Собрать один mono master ровно **109.000 секунд**:
  `submission/video/tenderverdict-vo-human-v1.wav`.
- Сохранить 48 kHz / PCM 24-bit; не нормализовать и не делать loudness master на стадии voice stem.

Metadata-only проверка, которая ничего не проигрывает:

```bash
python3 submission/video/validate_human_voice.py \
  submission/video/tenderverdict-vo-human-v1.wav
```

## Обязательная ручная проверка владельцем

- Прослушать финальный смонтированный ролик целиком на нормальной скорости.
- Проверить, что слышны все слова, особенно Test Store, **not an App Store payment**, **No real
  charge**, **without a purchase** и **not production billing**.
- Проверить синхронность с `captions-en.srt`, отсутствие обрезанных начал/окончаний и скачков room
  tone.
- Только после этого разрешать финальный mix/export. Upload и Devpost остаются отдельными gates.
